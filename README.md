# 🛒 Fake Store App

A responsive e-commerce web application built using **HTML5, CSS3, and JavaScript**. The application fetches real-time product data from the **Fake Store API** and displays products in a clean, responsive user interface.

## 🚀 Features

- 📦 Fetches products using the Fake Store API
- 🔍 Search products by title
- ⭐ Displays product ratings and review count
- 💲 Shows formatted product prices
- 📱 Responsive design for desktop and mobile
- ⚡ Built with Async/Await and Fetch API
- 🛡️ Error handling using Try/Catch
- 🎨 Modern card-based user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- DOM Manipulation
- Async/Await
